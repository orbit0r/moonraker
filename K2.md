# Creality K2 Plus branch (k2)

This branch is **Arksine/moonraker master** plus Creality K2 Plus patches
originally maintained by [Jacob10383/moonraker](https://github.com/Jacob10383/moonraker)
on branch k2, retargeted to **orbit0r/moonraker**.

## Why this exists

Creality firmware ships an older packaged Moonraker. After every Creality OTA,
community Moonraker under /mnt/UDISK stops being used and stock returns.
This fork keeps a current Arksine Moonraker that still works on K2 hosts.

## K2-specific changes

- In-place Klipper log rollover (no systemd unit)
- Creality Print gcode metadata identity
- Update Manager whitelist for orbit0r/moonraker on branch k2
- Writable symlink targets under /mnt/UDISK for K2 helper macros

## Install / restore after Creality OTA

See homelab-knowledge: docs/REFERENCE/K2-Moonraker-orbit0r-Restore.md

## Refreshing from upstream

1. git fetch upstream && git merge upstream/master into k2
2. Keep K2 behavior in the patched files if conflicts appear
3. Push k2
4. On each printer: pull /mnt/UDISK/root/moonraker and restart Moonraker
